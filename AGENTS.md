# AGENTS.md — AI Agent Guidelines

## Project Identity

This is an **AI skill** for building Minecraft Modrinth `.mrpack` modpacks. It is distributed via `npx skills add` and provides a 7-step workflow for resolving, validating, and packaging Minecraft mods.

**Primary use case:** AI agents use this skill to generate reproducible Minecraft modpacks with automatic dependency resolution, hash verification, and multi-loader support.

## Repository Layout

```
SKILL.md                  # AI skill definition — the contract agents follow (root for npx skills add)
skill/agents/openai.yaml  # Agent interface config (display name, invocation policy)
```

## Core Conventions

### Skill Development

- `SKILL.md` (repo root) is the **single source of truth** for how AI agents build modpacks
- The skill defines a 7-step workflow: analyze → select version → select loader → resolve deps → validate → preflight → generate
- All loader decisions must be data-driven; never hardcode a default loader
- Mods are declared with `slug`, `platform: "modrinth"`, `side` (both/client/server), and optional `note`

### Output Files (generated by the AI when the skill is invoked)

- `modpack/config.json` — declarative mod list
- `modpack/build.ps1` — PowerShell 5.1 build script
- `modpack/overrides/` — configs, server.properties, README.md

## Modpack Design Principles

1. **Stability over novelty** — prefer stable mod versions, avoid alphas/snapshots
2. **One mod per feature** — deduplicate: one recipe viewer, one minimap, one claims mod
3. **Required deps must be explicit** — transitive dependencies go in config.json mods list
4. **Client/server sides** — mark client-only mods so server env is `unsupported`
5. **No auth bypass** — never recommend or default `online-mode=false`

## When AI Agents Should Act

This skill is triggered when a user asks to:
- Create a Minecraft modpack (any loader)
- Add/remove mods from an existing pack
- Validate mod compatibility
- Generate `.mrpack` or `config.json`
- Set up a server with specific mods

The skill at [`SKILL.md`](SKILL.md) defines the full execution contract.
