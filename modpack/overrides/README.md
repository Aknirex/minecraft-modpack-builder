## 安装方法

1. 下载并安装 **Prism Launcher** (推荐) 或 **Modrinth App**
2. 将 `.mrpack` 文件拖入启动器窗口
3. 启动器将自动安装 Minecraft 1.20.1、Fabric Loader 和所有模组
4. 启动游戏即可

## 联机方法

### 方法一：e4mc (推荐)
1. 进入单人世界
2. 按 `ESC` → 点击左侧 **e4mc** 按钮
3. 点击 **"Open World"** 按钮
4. 将生成的公网链接分享给好友
5. 好友在多人游戏界面输入链接即可加入
6. **无需端口转发、无需自行搭建服务器！**

### 方法二：局域网 (LAN)
1. 确保所有玩家在同一网络下
2. 主机进入世界 → `ESC` → **"对局域网开放"**
3. 其他玩家在多人游戏界面即可看到

### 方法三：搭建专用服务器
- `server.properties` 已内置在整合包中，默认保留正版验证
- 将整合包中的 `server.properties` 复制到服务端根目录

## 领地的使用

1. 按 `M` 打开 JourneyMap 大地图
2. 在地图左上角点击 **"Open Parties and Claims"** 面板
3. 左键点击地图上的区块进行认领（绿色 = 你的领地）
4. 使用 `/openpac parties create <队伍名>` 创建队伍
5. 使用 `/openpac parties invite <玩家名>` 邀请好友共享领地
6. 更多命令: `/openpac help`
